# templates/

Reusable Markdown templates for creating governed artifacts in Mt. Olympus.

## Purpose

Provide consistent starting points for Knowledge Assets, decision records, session continuity, and governance standards.

## What belongs here

- Blank templates with required metadata fields and section structure
- Template README files explaining when to use each template

## What does not belong here

- Filled-in Knowledge Assets (those belong in `docs/`)
- Application code or automation scripts
- Finalized governance content presented as approved policy
- Session logs with actual session content (use `logs/daily/` for operational logs)

## Usage

Copy a template into the appropriate `docs/` subdirectory, assign an ID, set status to **Draft** or **Exploratory**, and complete all metadata before promotion.

## Status
