# docs/muses/

Definitions and guidance for durable domains of expertise (The Muses).

## Purpose

Muses represent enduring disciplinary structure — not agents, personas, or temporary assistants.

## What belongs here

- Muse catalog entries and domain definitions
- Scope and boundaries for each Muse
- Stewardship and expertise-area guidance

## What does not belong here

- Research notes (use `docs/research/` — cross-cutting activity, not a Muse)
- AI agent session instructions (those are temporary; see project instructions)
- Agent personas named after Muses
- Project-specific implementation work
- Decisions that belong in `docs/decisions/`
