## Decision

**Olympus** remains the official ecosystem name under **GDR-002**.

**Mt. Olympus** may be used as a display, narrative, or project-space alias when it clearly refers to the same Olympus ecosystem. It does not name a separate ecosystem, product, application, project, or authority domain.

Active assets should reference GDR-002 for identity and GDR-008 only when the presentation distinction matters.

## Context

Repository and project materials historically used both “Olympus” and “Mt. Olympus.” The variation was stylistic but had not been formally bounded.

## Options Considered

| Option | Outcome |
|---|---|
| Permit Mt. Olympus as a bounded alias | **Selected** — preserves familiar presentation without creating a second identity |
| Prohibit all Mt. Olympus usage | Rejected — unnecessary historical and presentation churn |
| Treat both names as separate identities | Rejected — contradicts GDR-002 |

## Consequences

- No broad historical rename is required.
- Active front-door material should make the official-name and display-alias relationship clear once, then reference the decisions.
