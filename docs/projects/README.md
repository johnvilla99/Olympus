# docs/projects/

Cross-project participation and ecosystem-level project context.

## Purpose

Document how participating projects (TripnetX, CraftHaus, Bank of Villasenor, Hobby Brain, and others) relate to Mt. Olympus without replacing project-local governance.

## What belongs here

- Project participation records
- Cross-project knowledge dependencies
- Ecosystem-level constraints or shared conventions
- Which assets each project must expose or consume

## What does not belong here

- Full project source code or application documentation
- Project-local decision records that belong in those repositories
- Replacement for per-project README or governance
- Implementation details unless promoted as a shared standard
