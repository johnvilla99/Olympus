# docs/concepts/

Concept records for emerging ideas before they become decisions or standards.

## Purpose

Capture exploratory thinking with clear non-binding status so future agents distinguish ideas from approved guidance.

## What belongs here

- Architecture/Concept Records (ACR-*)
- Seed concepts and origin stories
- Terminology proposals under exploration
- Conceptual models not yet approved

## What does not belong here

- Approved or canonical decisions (use `docs/decisions/`)
- Binding governance standards (use `docs/governance/`)
- Implementation specs or code
- Content presented as final without explicit promotion and approval
