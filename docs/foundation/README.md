# docs/foundation/

Core definitions that explain what Mt. Olympus is and why it exists.

## Purpose

Preserve the ecosystem's strategic foundation: problem statement, scope, conceptual model, and minimum viable knowledge foundation.

## What belongs here

- Foundation briefs and ecosystem overviews
- Terminology and conceptual model definitions
- Scope statements (in scope / out of scope)
- Milestone and maturity definitions for the knowledge foundation

## What does not belong here

- Approved decision records (use `docs/decisions/`)
- Governance process standards (use `docs/governance/`)
- Project-specific execution plans
- Implementation architecture or tooling choices
