# logs/daily/

Daily logs for Mt. Olympus repository and ecosystem work.

## Purpose

Record day-to-day activity, session summaries, and operational notes with a date-oriented layout.

## What belongs here

- Daily markdown logs (e.g. `YYYY-MM-DD.md`)
- Filled Olympus session handoffs (from `templates/sessions/`)
- Session activity summaries not yet promoted to governed assets

## What does not belong here

- Approved decision records
- Canonical governance documents
- Application runtime logs from other systems
- Sensitive credentials or private personal data
