# logs/

Operational and session-adjacent logs for Mt. Olympus maintenance work.

## Purpose

Capture ephemeral, time-bound activity that supports continuity but is not yet — or may never be — a governed Knowledge Asset.

## What belongs here

- Daily work logs and session activity notes
- Commands-run references and lightweight audit trails
- Temporary continuity notes pending promotion to assets

## What does not belong here

- Canonical Knowledge Assets (use `docs/`)
- Secrets, tokens, or credentials
- Large binary artifacts
- Content that should be a decision record or governance standard

## Note

Individual `*.log` files under this tree are gitignored. Directory README files and structure are tracked.
